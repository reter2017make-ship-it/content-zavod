Готовые видео

Ролики для ручной публикации. Кнопка «В готовые» кладёт файл в папку Готовые. Описание хранится здесь, в карточке ролика.

Файлы копируются без пересжатия в папку «Загрузки/Reels» как «reels 1.mp4», «reels 2.mp4»… (номера не повторяются), только видео. Скачанные ролики уходят в корзину: их можно вернуть, через 7 дней корзина очищается сама.
