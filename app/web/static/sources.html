🗓 Календарь

Добавить каналы

Вставьте одну или сразу много ссылок — через пробел, запятую или с новой строки: t.me/канал, t.me/s/канал или @канал.

Читается только открытая веб-версия канала, без входа в аккаунт. Большие видео Telegram в веб-версии не отдаёт — они будут в «пропущено», пока не подключён Telegram API (ниже).

Мои каналы из Telegram

Каналы и группы, на которые подписан ваш аккаунт. Отметьте галочкой, откуда брать видео: они будут парситься через Telegram API (большие видео тоже) по календарю, новые посты. В аккаунте ничего не меняется — только чтение.

Удалённые каналы
