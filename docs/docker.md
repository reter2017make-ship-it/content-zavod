# Контент-завод в Docker: запуск у другого человека

## Что передать

На своём Mac выполните `make share`. На Рабочем столе появится архив **`завод-для-передачи.zip`**, в нём только код и инструкции. Перед сборкой скрипт проверяет, что внутри нет ничего личного: ни `.env` с ключами, ни входа в Telegram (`credentials/`), ни базы, ни видео, ни моделей. Отправьте архив любым способом: Telegram, Google Drive, флешка.

Никогда не передавайте папку `credentials/`: файл `telegram.session` даёт полный доступ к вашему аккаунту Telegram.

## Что сделать получателю (Windows или Mac)

1. Установить **Docker Desktop**: https://www.docker.com/products/docker-desktop/ и запустить его (значок кита должен стать зелёным/«Running»).
   - Windows: при установке оставить галочку «WSL 2».
   - Mac: Docker Desktop работает на трёх последних версиях macOS.
2. Распаковать архив, например в `Документы/kontent-zavod`.
3. Открыть терминал в этой папке:
   - Mac: Терминал → `cd ~/Documents/kontent-zavod`
   - Windows: в папке правой кнопкой → «Открыть в терминале»
4. Выполнить:
   ```
   docker compose up -d --build
   ```
   Первая сборка идёт 10–20 минут: собирается локальная нейросеть.
5. Открыть в браузере **http://127.0.0.1:8765**.
6. «Источники» → «Telegram API»: ввести свои api_id и api_hash (выдаёт https://my.telegram.org → «API development tools»), войти своим номером, отметить свои каналы.

В фоне при первом запуске скачиваются модели: нейросеть Qwen 7B (~4,7 ГБ), распознавание речи (~0,5 ГБ) и русские голоса (~0,25 ГБ). Пока нейросеть качается, первые ролики разбираются дольше. Ход загрузки виден в `logs/models.log`. Нужно около 10 ГБ свободного места.

## Где что лежит (папки рядом с `docker-compose.yml`)

| Папка | Что там |
|---|---|
| `Готовые/` | готовые ролики |
| `Reels/` | «Скачать выбранные» из «Готовых»: `reels 1.mp4`, `reels 2.mp4`… |
| `data/` | скачанные видео, фоны, голоса |
| `database/` | база |
| `credentials/` | вход в Telegram и ключи — личное |
| `models/` | нейросеть и распознавание речи |

## Команды

- `docker compose up -d --build` — запустить или обновить после новой версии кода
- `docker compose down` — остановить (данные остаются в папках)
- `docker compose logs -f` — смотреть, что делает завод
- `docker compose restart` — перезапустить

Завод сам стартует вместе с Docker Desktop (`restart: unless-stopped`).

## Отличия от запуска на Mac без Docker

- Нейросеть работает на процессоре, а не на видеочипе Mac: разбор одного ролика ~30–90 с вместо ~10 с. Если медленно, в `config/config.yaml` можно поставить `ai.provider: rules` (оценка по правилам, без нейросети).
- Нет голоса Milena из macOS. Голоса Ирина, Денис, Дмитрий и Руслан работают.
- Вместо шрифтов Arial и Impact в роликах используются похожие свободные (Liberation Sans, DejaVu). Превью в браузере может немного отличаться от итогового ролика.
- Кнопки «Показать в Finder» и «Открыть папку» ничего не открывают: откройте папку `Готовые/` или `Reels/` вручную.
- Интерфейс открыт только на этом компьютере (`127.0.0.1`), из сети к нему не подключиться.

## Если что-то не так

- «port is already allocated»: порт 8765 занят. Поменяйте в `docker-compose.yml` на `"127.0.0.1:8766:8765"` и откройте http://127.0.0.1:8766.
- Страница не открывается сразу после запуска: подождите минуту и посмотрите `docker compose logs`.

## Instagram в Docker

Публикация в Instagram открывает видимое окно Google Chrome, а в контейнере окна нет. Для автопостинга ставьте завод обычным способом (Windows: `setup.bat` и `start.bat`, см. README). Остальное — парсинг, редактор, «Готовые» — в Docker работает.
