# Как подключить Instagram

Завод публикует Reels через официальный Instagram Graph API, вход через Facebook (Facebook Login for Business). Пароли от Instagram и Facebook завод не хранит и не вводит. Ему нужны только токен доступа и ID аккаунта, оба лежат в `.env` на этом Mac.

Видео загружается с Mac сразу на серверы Meta (resumable upload), публичная ссылка на файл не нужна.

Названия кнопок у Meta часто меняются. Если что-то называется иначе, ориентируйтесь на смысл шага.

## 1. Профессиональный аккаунт Instagram

1. В приложении Instagram откройте «Настройки» → «Тип аккаунта и инструменты» → «Переключиться на профессиональный аккаунт».
2. Подойдёт тип «Автор» или «Бизнес». С личным аккаунтом API не работает.

Для первой проверки лучше завести отдельный тестовый аккаунт.

## 2. Страница Facebook, связанная с этим аккаунтом

1. Создайте страницу Facebook, если её нет. Подойдёт любая, она может быть пустой.
2. Свяжите её с Instagram. В Instagram: «Настройки» → «Центр аккаунтов» → добавьте Facebook. Затем на странице Facebook: «Настройки» → «Связанные аккаунты» → Instagram.

## 3. Приложение Meta

1. Откройте https://developers.facebook.com, войдите своим Facebook и станьте разработчиком (бесплатно).
2. «Мои приложения» → «Создать приложение». Тип или сценарий выберите «Бизнес» / «Другое», затем добавьте продукт **Instagram** с вариантом **«API setup with Facebook login»**.
3. Приложение может остаться в режиме разработки. В этом режиме оно публикует в аккаунты людей, у которых есть роль в приложении. Вы администратор, поэтому для своего аккаунта проверка приложения (App Review) не нужна. Она понадобится, только если подключать чужие аккаунты.
4. В «Настройки приложения» → «Основное» перепишите **ID приложения** и **Секрет приложения**. Они нужны для автообновления токена.

## 4. Токен

1. Откройте Graph API Explorer: https://developers.facebook.com/tools/explorer
2. Справа выберите своё приложение, тип «User Token».
3. Добавьте разрешения: `instagram_basic`, `instagram_content_publish`, `pages_show_list`, `pages_read_engagement`. Если страница в Business Manager, добавьте ещё `business_management`.
4. «Generate Access Token». Войдите и разрешите доступ к своей странице и аккаунту Instagram (это делаете вы сами).
5. Скопируйте токен. Он короткий и живёт около часа, обменять его на долгий можно в шаге 5.

Есть вариант без продления: токен системного пользователя в настройках Business Manager («Пользователи» → «Системные пользователи»), он бессрочный. Права те же.

## 5. Подключение в заводе

1. Впишите в `.env`:
   ```
   META_APP_ID=…        # ID приложения
   META_APP_SECRET=…    # секрет приложения
   ```
   После этого перезапустите веб-интерфейс (`make web`).
2. Откройте http://127.0.0.1:8765/publish → «Подключение Instagram».
3. Вставьте токен, нажмите «Найти» и выберите свой аккаунт (ID подставится сам). Нажмите «Сохранить и проверить».
4. Нажмите «Обновить токен»: короткий токен превратится в долгий, примерно на 60 дней. Дальше завод сам продлевает его, когда до конца срока остаётся меньше 10 дней.
5. Проверка должна показать ✓ у всех пунктов: токен, разрешения, аккаунт, публикация Reels.

## 6. Первая публикация

1. Поставьте один ролик в очередь и нажмите «Dry-run». Все проверки должны быть зелёными.
2. Нажмите «Включить реальную публикацию». Ролик уйдёт в течение минуты, если не задано время.
3. Проверьте, что в карточке появились ID поста и ссылка «открыть в Instagram».

Если что-то пошло не так, карточка публикации покажет причину, HTTP-статус, код ошибки API и request ID. Кнопки: «Повторить», «Изменить», «Отменить». Подробности есть в `logs/factory.log` (строки `PUBLISH` и `INSTAGRAM`).

Чтобы остановить всё сразу, нажмите «Пауза публикаций» или «Вернуться в dry-run».
