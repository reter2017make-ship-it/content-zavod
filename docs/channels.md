# Каналы Telegram

2026-10-07 по просьбе пользователя оставлено по 3 канала в каждой сфере — те, где ролики требуют меньше всего правок. Остальные 52 канала удалены из источников. Скачанные из них ролики остались в базе и в `data/raw`.

Отбор шёл по данным базы (последние скачанные ролики каждого канала):

- доля уже вертикальных роликов (высота больше ширины в 1,5 раза), то есть почти без переделки под 9:16;
- качество исходника: короткая сторона кадра и средний битрейт;
- сколько роликов прошло фильтр качества.

Вотермарки и чужие плашки отдельно не проверялись.

Проверка прав отключена по решению пользователя: ролики публикует он сам и сам отвечает за права (см. CLAUDE.md, раздел 2). Источник каждого ролика по-прежнему записывается.
